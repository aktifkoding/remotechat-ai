# Frontend Development

## Instructions
Implement React/Next.js components with TypeScript, Tailwind CSS, proper loading/empty/error states, and accessibility attributes.

## Required Context
- Architecture Plan and UI/UX Design System.

## Execution Steps
1. Inspect existing UI primitives and state stores.
2. Implement components with strict TypeScript types.
3. Ensure responsive behavior and keyboard navigation.

## Expected Outputs
- Frontend component files and hooks.

## Validation Criteria
- TypeScript compiles cleanly with zero errors.
